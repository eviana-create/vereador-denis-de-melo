## 📌 Sobre o Projeto

Este projeto consiste no desenvolvimento de uma página institucional moderna e responsiva para **Denis de Melo**, com o objetivo de apresentar sua história, sua ligação com a comunidade e suas principais pautas de atuação.

A página foi construída com foco em:

- proximidade com moradores;
- valorização da história local;
- comunicação simples e humana;
- apresentação das causas comunitárias;
- facilidade de contato através do WhatsApp.

O projeto busca transmitir uma identidade popular, destacando a relação com a **Vila Moraes** e a região do **Grande Alvarenga, em São Bernardo do Campo - SP**.

---

# 🎯 Objetivo

Criar uma presença digital profissional, aproximando a comunidade através de uma página:

✅ moderna  
✅ rápida  
✅ responsiva  
✅ acessível pelo celular  
✅ fácil de atualizar
